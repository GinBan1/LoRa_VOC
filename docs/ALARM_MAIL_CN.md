# 中文事件邮件

ESP32 跟踪 STM32 在 AQ2 中已确认的固定规则事件，发送告警和恢复邮件。AI 分数不触发邮件；旧 AQ1 预测也不触发现版邮件。

## 配置

在 ESP-IDF `menuconfig` 的「空气环境 LoRa 网关配置 → VOC 事件告警」启用 QQ 邮箱通知，填写自己的 QQ 发件邮箱、SMTP 授权码和收件邮箱。授权码不是 QQ 登录密码。邮件默认关闭；网关需连接 Wi-Fi 并完成时间同步，OneNET 不是发信的必需项。

发件使用 `smtp.qq.com:465` 的隐式 TLS，校验服务器证书。配置步骤见[首次安装与烧录](OPEN_SOURCE_SETUP_CN.md)。

## 验证收件

1. 烧录并运行已配置邮件的 ESP32。关闭占用同一个 COM 口的监视器。
2. 打开串口助手（115200、8N1），发送小写 `mail test` 加换行；十六进制为 `6D 61 69 6C 20 74 65 73 74 0A`。须已启用串口测试入口。
3. 在收件箱或垃圾邮件箱查找「网关邮件测试」。日志中排队或 SMTP 接受不等于实收；收到测试邮件也不证明自然事件的报警和恢复已经通过。

测试命令不会修改告警状态或主动模拟污染。正式通知按节点已识别的会话和事件去重；过期、已失效的通知不补发，跨重启不保证恰好送达一次。调试结束后可以关闭测试命令入口，保留正常邮件功能。
